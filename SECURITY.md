# Security Policy

## Supported Versions

Only the latest release on the `master` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Velox, please do **NOT** open a public issue.

Instead, please send an email with the subject line `[SECURITY] Velox Vulnerability Report` to:
- **musahib.dev@gmail.com** (or via GitHub Private Vulnerability Reporting on the repository)

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept code.
3. Potential impact.

We will review the report promptly and provide an initial response within 48 hours.
